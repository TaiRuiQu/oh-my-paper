# Oh My Paper 教学工作台

把题库、组卷、作业、考试、阅卷和学习反馈连接在一起，让纸面教学材料能够持续复用。

教师可以准备题目与试卷、收集作答、检查评分并发布反馈；学生可以查看本人已发布的学习结果并完成后续练习。学校按教学岗位分配协作范围。
