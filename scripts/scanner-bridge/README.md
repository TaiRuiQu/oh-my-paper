# 把扫描仪接入你的教学工作台

已有纸面答卷，也可以集中进入 Oh My Paper。你可以直接上传图片或 PDF；使用兼容扫描仪时，还可以从网页采集图像，减少手动搬运文件。

## 开始之前

在连接扫描仪的电脑安装 Python 3。USB / SANE 设备还需要安装 sane-utils，并确认 `scanimage --list-devices` 能找到设备；网络扫描仪需要支持 eSCL，并提供设备实际的 eSCL 地址。

在该电脑的项目目录运行下面的示例，把网站地址和扫描仪地址替换成自己的值：

```bash
python3 scripts/scanner-bridge/bridge.py --origin https://paper.example.com --escl office=http://192.168.1.20/eSCL
```

本地体验时可将 `--origin` 改为 `http://localhost:3000`。扫描服务默认只监听本机，启动后会显示随机令牌。不要把令牌发给其他人或提交到仓库。

## 在网页中采集

打开扫描页面，选择「连接扫描仪」，填写本机桥接地址与启动时显示的令牌，查找设备后开始采集。浏览器可能要求允许网站访问本地网络；如果 HTTPS 页面无法访问本机 HTTP 服务，需要配置受信任的本机 HTTPS 代理。

平板模式每次采集一页。支持 eSCL 的自动进纸器可选择单面或双面、分辨率及单批 1–100 页上限；达到上限后可继续下一批。SANE 设备当前按单页采集，可重复添加后统一上传。

采集后检查方向、清晰度和学生页序，再提交处理。不同设备的支持情况可能不同，正式整班扫描前请先做少量试扫；当前项目的自动化协议测试不能替代真实设备验收。
