# v2 浏览器实际操作验收

日期：2026-10-14。使用真实本机 Next.js 服务、PostgreSQL 和外部公开模型；浏览器为 agent-browser 的独立 `omp_v2_frontend` 教师 session 与 `omp_v2_student` 学生 session。先完成非 AI 点击闭环，随后执行 AI 六任务。模型接口兼容及输出上限修复前的失败保留为历史记录，以下 AI 通过结论只引用后续成功任务。

## 非 AI 全流程

1. 从注册页实际填写并注册教师验收账号；注册默认学生，由授权数据库操作将隔离验收账号提升为教师。第二个学生账号保持 STUDENT。
2. 在题库表单输入单选题、四个选项、标准答案、评分标准、知识点和数学公式，保存后在题库显示。错误提交时编辑内容保留。
3. 在组卷界面新建考试试卷，从题库点击选入，确认题序、栏目与 5 分分值，保存后列表显示一题、总分五分。
4. 创建班级与六位卡号学生，创建单科考试并关联班级与试卷。
5. 制作并保存由真实模板生成器生成的答题卡；实际移除并重新生成题区；上传站内题区配图，保存已扫描模板被拒绝且表单保留，使用另存按钮成功创建含配图模板。
6. 由实际模板 SVG 栅格化产生填涂卡号 000001、选项 B 的扫描测试图，在上传控件选择图像并提交，界面显示成功导入一份，学生身份和选项作答正确。
7. 在人工阅卷界面选择学生答卷，输入分数及反馈，提交后显示最终得分；发布成绩后成绩表显示科目分、总分和排名。
8. 学生考试后首次注册，在教师界面补绑定其账号；学生独立 session 只显示「我的学习」，可查看本人已发布成绩、排名、错题和知识点表现。
9. 在练习册模式上传原图，真实 mouse down/move/up 拖动将题区改为 x=10%、y=19.94%、width=70%、height=15.05%；图像覆盖框和精确坐标同步更新。
10. 复合题使用独立测试 fixture 创建已有作答，在真实 UI 输入第一问 0/2 分及反馈、第二问 3/3 分及反馈，合计自动更新 3/5；保存、发布后学生知识点显示 UI计算 0/2（0%）、UI证明 3/3（100%）。fixture 仅准备数据，实际评分、发布与学生查看均通过页面操作。

## 实测局限

未连接实体扫描仪、打印机或实体触屏设备；软件扫描协议、扫描栅格图像及桌面框选不替代硬件现场验收。浏览器未重复覆盖每个题型每个输入分支；五题型结构、双评仲裁、并列排名与权限边界由对应真实数据库、HTTP 和 AI 验收补充证明。

## 独立复审修复验收（2026-10-14）

- 考试/班级/学生筛选现在调用 `/api/platform/analytics` 获取相同范围的汇总，服务器保留真实联考排名与赋分，学生浏览器不接收他人评阅记录。实际学生点击切换「复合题UI验收作业」时学科 3/5（60%）、错题 1 题、知识点仅 UI计算 0/2 与 UI证明 3/3；切换「前端验收期中考试」时学科 0/5（0%）、错题 1 题、知识点仅数的运算 0/5。标题数量、列表、学科汇总与知识点一起更新，不混入其他考试。
- 练习册首次选卷及上传图片的区域列表为空；真实键盘聚焦「添加第 1 题答题区域」并按 Enter，创建当前页区域并展开精确坐标。键盘填写 X=0.1 后覆盖框同步显示 left=10%；页码上限为实际上传一页。提交前验证每题唯一完整覆盖、页码范围及区域边界。截图 `.impeccable/review/workbook-keyboard.png` 保存键盘创建后的坐标界面；`student.png` 已更新为指定考试统计。
- 新增 `tests/platform-ui-scope.test.tsx` 两项有状态 UI 回归：学生没有 reviews 时考试筛选同时改变知识点、学科与错题计数；没有指针操作也能创建首个区域并打开当前页坐标。两项均通过，TypeScript 和所改文件 lint 通过。
- 修复后练习册界面 axe-core：0 violations、0 incomplete、27 passes；学生学情界面：0 violations、0 incomplete、26 passes。

## 扫描仪批量界面实际验收（2026-10-14）

使用独立教师浏览器、真实本机 HTTP 模拟 eSCL 设备和未修改的 `scripts/scanner-bridge/bridge.py`，实际点击查找设备、选择自动进纸器、双面、300 DPI、页数上限 10，并点击批量扫描。设备收到 Feeder / Duplex=true / 300DPI 的创建任务 XML，返回先 PNG 后 JPEG 的两页；网页待上传列表顺序为 `-1.png`、`-2.jpg`，实际 File MIME 保持 `image/png`、`image/jpeg`。不可用设备选项禁用。随后模拟设备创建任务返回 HTTP500，页面显示错误，已有两页保持完整且顺序不变。没有上传测试采集图覆盖已阅答卷。
