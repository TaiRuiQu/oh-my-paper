# 教学平台结构重构：独立 UI 与交互验收

## 1. Disposition 与范围

**当前 Disposition: ship（限定本次多页面结构与已报告 F1–F8 的 Chromium UI 验收范围）。两轮集中修复复验后，F1–F8 均 resolved；不等同于全部业务边界、硬件、物理触摸和实际 A4 打印均已验收。**

独立审查对象是 2026-10-14 根 agent 提供的 `http://localhost:3001` 生产候选，覆盖 `page-map.json` 全部 **85 个 App Router 页面**（管理员4、教师75、学生6），桌面 **1440×1000** 与手机 **390×844** 各一次真实 Chromium 渲染，共170张逐页截图。另核对管理员、教师、学生 `/workspace` 首页；对异步报告等待请求完成后补拍。审查采用 Impeccable 与 agent-browser，使用两个隔离 session；审查者没有修改产品代码。

结构与视觉总体成立：浅灰工作区、白色纸张、教学蓝主要操作、中文字体和紧凑表格保持一致；首页、作业、考试、题库各有明确入口，复杂任务使用独立 URL。试卷、练习册和答题卡分别有纸面编辑状态与业务逻辑，不是仅换标题的同一列表/弹框。85页均有单一主标题，170次采集均未出现整页横向溢出，表单未发现无标签的原生输入控件。**这些是覆盖与基础质量证据，不代表85页所有按钮、错误和边界均已通过。**

初始候选的主要阻塞是30页主要操作文字不可读、未保存后退丢失、答题卡键盘缩放错误，以及编辑/导出/打印不一致。初始候选技术评分为：可访问性2/4、性能3/4（未做压力基准）、响应式2/4、主题3/4、实现完整性3/4，总计13/20。静态 detector 为0个主发现、17个品牌刻度 advisory；纸张黑线、印刷字体和旧 tokens 的 advisory 不直接视作产品缺陷。

## 3. 按严重度列出可复现问题

以下保留初始发现、复现与定位；最新resolved/partial/unresolved裁定见第1节，不把已修复问题继续作为当前失败。

### F1 · P1 · 30页主要 Link 文字与蓝色背景同色

复现：以教师打开 `/exams`、`/exams/papers` 或 `/homework`，主要操作呈蓝色实心块，文字不可读；管理员/学生共享的同类入口也受影响。计算样式为 `color: rgb(36,89,211)` 与 `background-color: rgb(36,89,211)`，对比度1:1，违反 WCAG 1.4.3。30个路由的逐页矩阵已标 F1，手机同样失败。用户难以发现创建、布置、录入、打印等核心动作。

定位：`src/components/ui/button.tsx` 的 Slot/asChild 属性与 `src/app/globals.css` 主要链接覆盖规则。建议让 ShadCN Button 的 `data-slot`/variant 标识实际落入最终链接，并统一主要 Link 前景为白色。初始候选当时尚未包含源码补丁；第一轮已实际复核30个路由的计算前景与可见文字并判 resolved，见第1节。

### F2 · P1 · 浏览器后退绕过未保存提示

复现：打开试卷概览 →「继续编辑」→ 将第1题分值10改为11 → 出现“有未保存的修改” → 浏览器 Back。页面立即回概览，没有确认，修改丢失。内部链接取消则能保留卡面编辑，说明问题特定于历史导航。

定位：`src/components/platform/use-unsaved-changes.ts:8` 只监听 `beforeunload` 与文档 click，没有保护同文档历史导航。影响长时间排版工作的可靠性。建议统一离开保护覆盖 Back/Forward，并保证取消后 URL、编辑状态、历史位置均保留，确认离开后正常前进/后退；不能用重复 push 历史记录制造回退陷阱。

### F3 · P1 · 答题卡缩放手柄的键盘操作实际移动题区

复现：`/exams/cards/aa45b0ce-37ce-4385-b75c-2156db649275/edit`，聚焦“缩放第1题答题区”，按 ArrowUp，top减少0.1%，height仍16.919%；按 ArrowRight，left增加0.1%，width仍86.1461%。父题区方向键移动正常，鼠标移动也正常。键盘用户无法完成缩放，且会意外改动位置。

定位：`src/components/platform/card-workbench.tsx:783` 的 resize `onKeyDown` 未 `stopPropagation()`，事件冒泡至父题区 `keyboard`，以旧 layout 覆盖子元素的尺寸更新。建议阻止冒泡，并校验键盘缩放的最小尺寸、边界与焦点；复核宽高变更而 x/y 不变。

### F4 · P1 · 编辑纸面与导出预览的分页不同

复现样本：保存练习册 `c6072f46-919d-43df-8124-bb44edb44201`，第1题7行、其他题4行。相同A4、18mm、11pt、1.8行距，编辑页稳定显示3页，导出预览稳定显示2页。实际打印HTML的作答行数正确保持 `[7,4,4,4,4,4]`。用户在纸面调整分页后无法预测下发结果。

定位：`src/components/platform/document-canvas.tsx:86` 测量整块编辑DOM；`homework-workbench.tsx:437` 之后的分值/排序按钮与作答行数字段参与块高度，而导出块没有这些控件。`paper-pages.tsx:568` 与导出预览也使用不同正文结构；`src/server/platform/print.ts:63` 又单独实现打印HTML。建议编辑/只读预览/打印共享实际正文几何，工具放在不占版面位置的层；统一标题、栏目、说明、正文、字号行距、间距和分页规则。应复核页数和每页题目起止，不只比较总行数。证据有编辑截图和PDF；CLI PDF默认Letter，仅作为辅助，不能替代A4实物验收。

### F5 · P1 · 打印丢失已保存的栏目名称

复现：试卷副本 `f0858b68-5b7a-44c3-b447-23b5f00f13c0` 的第1题栏目保存为“独立验收栏目”；概览/导出页面能显示该内容，打开 `/api/platform/print?paperId=...` 正文完全没有栏目。用户编排的大题层级在下发试卷中消失。

定位：`src/server/platform/print.ts:63` 的 `renderPaperHtml` 未输出 `item.section`。建议明确栏目分组规则并在纸面、导出和打印使用同一渲染；验证重复栏目、跨页栏目和空栏目，而不是只拼接一次测试词。

### F6 · P2 · 禁用状态错误显示为永久“正在保存…”

复现A：已发布的考试/作业逐题评阅页，6个评分按钮均显示“正在保存…”，但没有请求，分数/反馈字段仍可编辑，提交永久禁用。复现B：`/exams/new` 与 `/homework/assignments/new` 未选试卷时，同样显示“正在保存…”。用户无法判断保存是否完成、字段是否有用。

定位：`review-pages.tsx:207` 使用 `pending || assessment.published`，`assessments.tsx:230` 使用 `pending || !papers.length || !classrooms.length` 传入 `Submit.pending`；`primitives.tsx:53` 把所有 pending 变成保存中。建议分离 loading、disabled、readOnly；已发布评分明确只读并引导撤回，无可保存内容时保留“保存安排”标签和原因，只有真实请求显示保存中。

### F7 · P2 · 手机纸面控件缩至14px，卡面右边缘被局部裁切

复现：390×844打开练习册编辑，fitWidth为0.387909；排序按钮13.95×13.95px、分值输入高13.95px、作答行数输入高15.52px。精细操作易误触，字体也随纸面整体缩小。答题卡预览 clientWidth322、scrollWidth384，sheet最小360px，右边题区/10×10px缩放手柄需横滚后才能触及；没有适应宽度或滚动提示。

定位：`document-canvas.tsx:70` 整个编辑DOM使用CSS zoom，`globals.css:1357`/`:1468` 的纸面工具随之缩小；`globals.css:1497` 的卡面 min-width 与`:1583`的10px手柄。建议手机把选中题目的分值、排序、作答行数放在未缩放的属性工具区，保持可靠目标尺寸；提供清楚的放大编辑/适应宽度或滚动提示。保留纸张比例与局部滚动可以接受，不能只以整页没有溢出认定手机编辑可用。本轮仅做模拟视口与鼠标/键盘，未把布局截图冒充真实触摸通过。

### F8 · P2 · 练习册录入页仍使用答题卡扫描说明

复现：`/homework/submissions/new` 主标题是“录入练习册作答”，内部说明仍要求理解“答题卡按识别位点矫正、卡号匹配…”和“规范答题卡按模板页数、文件顺序合并…”。功能选择已正确锁定WORKBOOK，但描述混入考试规则，教师可能误以为日常作业也必须制作独立答题卡。

定位：`src/components/platform/scans.tsx:223` 与`:312` 的无条件说明。建议按 fixedKind 提供独立的练习册说明：指定学生、选择原图、框选每题作答范围；答题卡识别与多页模板说明仅在考试录入出现。
