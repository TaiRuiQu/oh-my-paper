# 教学平台结构重构

本次目标是将所有功能拆成 50–100 个独立、完整的路由页面，同时保留现有浅色、蓝色主操作、中文字体和紧凑列表风格。不能以页面数量代替功能完整性。

## 结构约定

- 主导航为首页、作业、考试、题库。教学班级归入首页；管理员另有系统管理；学生看到本人学习入口。
- 每个业务模块有列表、创建、详情与独立操作页。URL 表示当前任务，刷新、后退、直接访问都必须有效。
- 试卷以完整工作台呈现：概览、可视化编辑、答案、排版与导出；编辑直接发生在纸面，支持排序、分组、分值与题目内容。
- 作业只能使用练习册录入，不制作或扫描独立答题卡；考试支持扫描答题卡。
- ShadCN UI 组件继承当前品牌 tokens，交互统一。复杂编辑使用独立页面，确认性操作才使用对话框。
- 后端按题库、试卷、教学班级、考试安排、作答与评阅拆分服务；授权与事务规则统一。页面读取经过权限与模块范围限定的数据。

## 验收门槛

1. 检查全部路由具有独立标题、明确任务、正常空态、错误恢复和完成动作。
2. 教师、学生、管理员首页使用真实数据且符合权限。
3. 创建题目 → 组卷 → 布置 → 录入 → 评阅 → 发布 → 学生报告能够实际完成，考试与作业分别验证。
4. 全部页面在桌面和手机保持统一样式、可达导航和可用表单。
5. 后端授权、事务、不完整成绩不可发布等原有业务约束仍然有效。
6. 运行格式、lint、类型、领域与集成检查；浏览器核对关键任务。
7. 实现完成后独立 subagent 审查全部页面的样式与人类交互逻辑；处理审查发现后才能声明完成。

## 当前状态

已实现 85 个独立 App Router 页面，清单见 `page-map.json`。试卷、作业、答题卡各有独立的可视化排版工作台，基础纸张渲染共享 `DocumentCanvas`，业务编辑状态分别维护。

已完成独立逐页审查与两轮集中修复复验。审查覆盖 85 页、桌面与手机共 170 张截图；8 项发现已由独立 reviewer 逐项判定 resolved，结论与范围见 `structure-ui-review.md`。格式、lint、类型与 60 项单元测试通过；真实 PostgreSQL 领域、HTTP、扫描和 AI 原子性验收通过。

原始代码只有一个 `/workspace` 入口和查询参数 tab，现已移除该页面分发器与旧混合工作台。现有 DESIGN.md 的视觉 tokens 保留；其旧路由说明不能作为本次结构验收证据。既有未提交 docs 删除保留，不属于本次改动。

## 排版工作台约定

- 试卷：题库选题、卷面直接编辑、题序与分值、栏目、分栏、纸张大小、页边距、字号、行距和逐题分页；本卷题干／答案修改保存为独立快照。
- 作业：独立练习册画布，题目与作答区域共同排版，逐题设置作答行数与分页，进入班级布置与练习册批改。
- 答题卡：A4 卡面拖动题区、缩放题区、调整学号区和定位点，支持多页与精确坐标。保存前校验不重叠与全题覆盖；打印和扫描使用持久化的同版式坐标。
- 新建和修改均在页面内完成，复杂编辑不会打开另一个编辑弹框。离开未保存编辑页有提示；已布置内容另存为新版，保留原始成绩依据。
