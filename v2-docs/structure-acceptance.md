## 已完成的自动验证

- `pnpm run check`：格式、lint、Next 路由类型、TypeScript、60项Vitest测试通过。
- `pnpm run build`：全部平台页面与API生产编译通过。
- `pnpm run test:integration`：真实隔离PostgreSQL，权限、五题型、卷内快照、版面保存、作业答题卡拒绝、双评与仲裁、排名、发布和历史名单通过。
- `pnpm run test:http`：实际登录与会话、角色、素材、题库至发布与学生报告、scoped analytics通过。
- `pnpm run test:scan`：透视矫正、多页匹配、异常、练习册裁切与历史名单通过。
- `pnpm run test:ai-domain`：AI持久化、过期数据拒绝、小问评分、原子失败通过；未调用外部模型。
- `pnpm run test:ai-jobs`：后台队列、并发、租约、状态记录、显式重试与权限通过。
- 85个路由按教师／学生／管理员角色以真实样本直接访问，全部200且具有页面标题；学生考试数据API403，跨业务域命令400。

浏览器原始证据保存在 `.impeccable/review/structure`。教学样本明确标记「结构验收」。自动结果只证明所列范围，独立逐页审查与修复复核的结论仅覆盖报告所列浏览器范围；实体扫描仪、真实触屏与物理打印没有现场验收。

## 独立复验闭环

- F1：原30页主要操作链接，桌面／手机60次渲染确认白字蓝底，文字可读。
- F2：未保存后退取消保留URL与草稿，确认正常返回，历史长度与索引无重复条目。
- F3：答题卡缩放手柄键盘仅改变宽高；题区方向键仍用于位置微调。
- F4：操作控件从打印几何中分离；固定1倍尺寸测量，桌面／手机和不同缩放下同稿均2页。打印实际加载与应用相同的Geist/Noto字体。
- F5：保存的栏目名称包含在打印正文，题目快照、作答行和题序保留。
- F6：已发布评分为明确只读状态；未选试卷的创建表单禁用但不显示假保存状态。
- F7：手机有独立40px题目属性区、100%编辑与适应宽度；卡面适应屏幕并有44px缩放目标。
- F8：练习册录入使用独立说明、字段和图片顺序提示。

独立评分样本均明确标记「结构验收」，考试和作业分别经实际UI评分、发布，学生独立会话读取60分。打印与屏幕核对属于软件范围，不表示实际打印机、纸张与实体扫描设备已经验证。
