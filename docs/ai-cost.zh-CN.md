# AI 任务成本

每个 AI 任务完成或失败后，任务列表和处理进度页显示本次任务的人民币估算成本。展开成本详情可查看美元金额、计价模型、价格获取时间、汇率及其更新时间。失败任务只包含已返回用量的调用，实际扣费以供应商账单为准。

程序运行时请求 `https://models.dev/api.json`，读取对应供应商及模型的美元单价（每百万 Token）。价格缓存一小时，并合并同一进程内的并发请求。优先按接入地址匹配供应商，再按供应商名称匹配；未知中转接入仅在模型能明确对应目录记录时使用参考价格，并在页面注明。无法明确匹配的模型显示「成本暂无法估算」。

每轮模型调用独立计算非缓存输入、缓存读取、缓存写入、普通输出和推理输出的费用；推理用量已包含在总输出中，不重复计费。根据每轮输入长度选择长上下文阶梯价，再累加整个任务（包括任务中的多个 Agent）的费用。目录未单独提供缓存或推理单价时使用对应的普通输入或输出单价。

美元兑人民币汇率从 `https://open.er-api.com/v6/latest/USD` 动态获取，缓存一天。如果请求失败或返回无效数据，使用代码中保存的 **1 USD = 6.706494 CNY**，这是 ExchangeRate-API 在 **2026-10-15 00:02:31 UTC** 发布的汇率。页面会明确说明使用了备用汇率。失败的价格和汇率请求一分钟后可重试，不影响 AI 任务执行。

累计用量、美元及人民币金额、价格和汇率快照写入 `ai_jobs.cost`，独立于执行事件的条数限制。结果提交前已保存成本，因此导入、评分和巩固卷等原子提交完成后即可展示；查询历史任务时不会重新计价。未返回完整用量时不显示虚假的零元，确实零价的模型显示 ¥0.00；非零的小额费用至少显示四位小数或「< ¥0.0001」。

部署时执行 `pnpm run db:deploy`，应用 `20261025000000_ai_task_cost` 迁移。无需配置价格或汇率密钥。
