# AI 批改

批改使用已经保存的标准答案和评分标准。完整的试卷录入、答案解析及题套上传流程见 [试卷与批改流程](paper-workflow.zh-CN.md)。

## 标准答案是前置条件

所选题目必须有可用的保存标准答案，或由教师在批改设置中填写参考答案。缺少标准答案时接口返回 `409`，要求先补充或生成答案；批改 Agent 不在评分时生成参考答案。上传试卷时关闭答案生成的题套，可以在保存后补生成。

`solution` 阶段优先整理原件中的参考答案，生成答案时只使用干净电子题目及必要的材料图片。多小问、多空题按 `answerTargets` 保存逐项答案与解析。可用的 AI 答案可以直接参与批改，教师可以编辑；“可用”表示通过结构和完整性检查，正确性仍需核对。

## 每题读取完整作答文档

作答解析 Agent 将文字、非文字图像、跨页片段及无法确定题号的片段保存在完整 `answerDocument` 中。每道题的批改 Agent 都收到完整文档和全部非文字作答图，再自行识别本题答案，返回匹配的 `sourceId` 与有序内容块。

程序检查匹配来源是否存在、必要图像是否齐全、答案是否明确归属本题。归属不明、无法辨认或证据缺失时保留待核对。完整文档中明确匹配的空白作答可以判零分；无法辨认不能视为未作答。教师主动修改的作答按提交的明确输入处理。

题目材料和学生作答图保存不同的资产 ID 与 `role`。即使图像的页码和坐标相同，也按各自资产读取。Agent 工具只能放大答案解析阶段保存的授权裁切图。

## 分数与人工核对

模型返回逐评分点的得分、依据与评语。多小问、多空题的评分点须通过 `targetKey` 覆盖每个作答项。程序校验评分点合计、题目满分、得分边界和判定一致性，再以整数分币汇总。

分值未知、题目或材料不完整、作答不明确、评分结果不一致或模型明确要求核对时暂不计入正式分数。报告区分已计分与待核对题目。教师可以修改分数和满分、填写原因，修改历史随报告保存；有效分数改变后更新错题状态。

## 任务与版本

- 每次最多批改 300 道题。同一份作答同时只允许一个批改任务；普通模式每用户最多同时 3 个任务，班级批次入口上限为 100 个。
- 默认总模型调用预算为所选题数乘以 4，预算在并发调用前预留。Agent 步骤和修复调用计入预算，失败请求也会占用预算；达到上限时保留未完成题目。
- 批改总时限为两小时，单次模型请求另有提供商超时。逐题保存检查点，Worker 恢复时只复用同一评分提示词版本的已完成结果。
- 报告保存提交时的题目、标准答案、作答、图像引用、模型配置及来源版本。编辑题套或切换模型不会改写已有报告；班级批次复用创建时固定的题套版本。
- 原图、非文字作答证据、下载和人工修分均检查访问权限。非文字作答可以在报告页面和 HTML 下载中按原顺序查看。

## 验证

`pnpm test` 覆盖标准答案前置条件、完整作答文档、错误题号提示、未归属片段、空白与不可辨认区分、资产匹配、多空评分点、调用预算和断点恢复。

Web/Worker 启动后运行 `pnpm run test:exam-web`，使用本地模拟模型检查题套固定版本、答题卡、答案复用、关闭生成与补生成、缺少答案拒绝批改、报告证据权限和导出。该命令不调用付费模型。更多验证说明见 [集成验证](ai-web-validation.md)。
