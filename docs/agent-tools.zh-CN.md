# AI 能帮你做什么

从重复录入中省下时间，把精力留给题目质量、学生理解和课堂讲评。Oh My Paper 的 AI 功能围绕日常教学提供帮助，生成的结果可以回到工作台继续检查和编辑。

| 教学场景       | 可以获得的帮助                    | 需要你核对的内容               |
| -------------- | --------------------------------- | ------------------------------ |
| 旧卷入库       | 从图片和 PDF 整理题目、配图与选项 | 模糊文字、公式、图表和题目边界 |
| 完善题库       | 补充参考答案、解析和知识点        | 解法、答案与课程要求是否一致   |
| 准备试卷       | 按要求选题组卷，辅助安排答题卡    | 题目覆盖、分值、版面和作答空间 |
| 批改作业与考试 | 查看作答，给出候选评分与反馈      | 评分标准、识别异常与最终分数   |
| 课后巩固       | 根据错题选取相关练习              | 题目是否适合学生当前学习阶段   |
| 备课           | 辅助整理教学计划与材料            | 内容准确性和课堂适用性         |

## 怎么开始

管理员接入模型后，教师可以在对应功能页面启动 AI 任务，也可以直接向[小纸](xiaozhi.zh-CN.md)描述目标。上传材料时尽量保证页面完整、文字清晰；提出要求时说明学科、适用年级、题数与使用场景。

## 看得见进度，也保留人工判断

任务页面会展示处理进展、需要核对的内容和结果入口。AI 可能遇到无法辨认的图片、题库不足或模型服务错误，平台会给出处理提示。结果不符合预期时，先查看具体原因，再补充材料或调整要求。

考试支持人工阅卷、双评与仲裁。AI 是辅助教学的工具，正式成绩仍需要有权限的教师确认与发布。模型调用费用见 [AI 费用说明](ai-cost.zh-CN.md)。
