# 任务进度与失败重试

上传一批试卷后，你可以在 AI 任务页面查看处理进度、结果和需要核对的内容，不必一直停留在原页面等待。

## 任务状态告诉你什么

- **排队中**：任务已提交，等待后台开始处理。
- **处理中**：正在读取材料、识别、评分或整理结果。
- **已完成**：打开结果链接，检查内容并继续编辑或使用。
- **失败或已停止**：先阅读原因，再决定补充材料、修改设置或重试。

排队成功表示系统收到任务，最终结果以任务完成状态为准。处理过程中网络断开，可恢复网络后重新打开任务页面；后台服务正常运行时，页面关闭不会终止任务。

## 遇到问题怎么处理

| 看到的情况       | 建议操作                                         |
| ---------------- | ------------------------------------------------ |
| 一直排队         | 请管理员检查 AI Worker 是否在运行。              |
| 图片无法识别     | 补充清晰、完整、方向正确的原图。                 |
| 模型不可用       | 请管理员检查服务地址、密钥、余额和模型能力。     |
| 候选题不足       | 先扩充相关学科、年级与知识点的题库，再生成练习。 |
| 评分与预期不一致 | 核对作答和评分标准，由教师复核分数。             |

重试可能再次产生模型费用。小纸已经完成的业务操作不会因停止自动撤销，请先到结果页面查看，避免重复创建。

管理员需要排查部署问题时，可参考[部署指南](deployment.zh-CN.md#常见问题)。
