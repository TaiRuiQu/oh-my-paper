# v0.1.14 部署与升级指南

本版本新增 Gemini Interactions API 接入，失败重试沿用原任务模型，同时精简 Agent 提示词、补充 Python 数值计算库并提高工具参数的容错能力。

## 功能变化

- 新增「Gemini Interactions API」（`google_interactions`）配置，支持流式输出、图片、多轮工具调用和推理强度设置。官方 Base URL 为 `https://generativelanguage.googleapis.com/v1beta`，兼容供应商填写其 API 根地址。已有 Google Generative AI 配置继续使用 Generate Content，无需修改。
- 试卷识别、答案生成和提取、学生批改及答题卡相关 Agent 的系统提示词只保留目标、任务和基本公式约束，工具操作规则移入 Tool Description。
- 所有 Agent 的 LaTeX 只用于基本数学公式，不使用复杂布局、对齐、间距、字体、字号或颜色控制；文字说明和表格使用 Markdown。
- 删除 `read_question`，答案和批改统一使用 `read_questions`。一次可读取 1–50 道题，单题在 `questionIds` 中传一个 ID。
- 删除 `shell`、`python` 的旧 `replacePages` 参数。页面更新通过直接覆盖 `/workspace/pages/001.jpg` 等文件完成，后续工具调用与材料裁剪使用更新后的页面。
- Python 沙箱预装 NumPy、SciPy、SymPy 和 mpmath，支持数值和符号计算；保留 Pillow 和 OpenCV 图像处理能力。Worker 镜像按固定版本安装这些依赖。
- `gradingCriteria` 改为可选，提示词要求只为主观题或混合题中的主观小问提供评分标准，客观题省略。数据库以空字符串保存未提供的标准，界面隐藏空值；重新发布省略该字段的答案会清除旧评分标准。
- 所有失败任务的重试沿用原任务的模型和完整提供商配置快照，包括推理强度；后台默认模型、用户偏好及页面当前选择不再覆盖重试配置。快速批改按失败阶段沿用原任务配置，答题卡任务继续保留原配置。
- 所有 Agent 工具忽略未声明的输入字段，包括嵌套字段，并在结果的 `warning` 中列出字段路径。必填项、类型、数值范围和业务规则仍严格校验。警告也会保留在带图片的工具结果和执行记录中。

## 验证

273 项单元测试、数据库集成测试、类型检查、Lint 和格式检查通过。实际沙箱验证了线性方程求解、数值积分、符号方程和高精度计算；SDK 测试验证了 Gemini 两种协议的流式工具调用与图片历史、额外字段警告和不含评分标准的答案保存。Web 与 Worker 生产构建通过。

## 升级

从 v0.1.13 升级没有新增数据库迁移或必填环境变量。Web 与 Worker 使用同一版本，镜像支持 `linux/amd64`：

```text
ghcr.io/tairuiqu/oh-my-paper:v0.1.14
ghcr.io/tairuiqu/oh-my-paper-worker:v0.1.14
```

发布同时更新 `latest`。固定版本时将部署 `.env` 的 `APP_VERSION` 设为 `v0.1.14`，在部署目录执行：

```bash
docker compose -f compose.yaml -f compose.release.yaml pull migrate web worker
docker compose -f compose.yaml -f compose.release.yaml stop web worker
docker compose -f compose.yaml -f compose.release.yaml run --rm migrate
docker compose -f compose.yaml -f compose.release.yaml up -d --wait web worker proxy
docker compose -f compose.yaml -f compose.release.yaml ps -a
```

确认 Web、Worker 为 `healthy`，页面显示 `v0.1.14`。使用源码运行 Worker 时，先在其 Python 虚拟环境中执行 `pip install -r tools/python/requirements.txt`；发布镜像已包含这些依赖。已有答案和批改记录保留，历史客观题的评分标准不会自动重写。从更早版本升级需执行此前迁移，参见[通用部署手册](../deployment.zh-CN.md)。
