# v0.1.9 部署与升级指南

本版本新增答题卡批量批改和文档扫描预处理，修复 Anthropic Messages 与火山 Agent Plan Responses 接口兼容问题，页面左下角显示当前版本。

## 功能变化

- Anthropic 自定义网关自动补齐 `/v1/messages` 的版本路径，已带版本的地址不会重复拼接。阿里云与 MiniMax 的文本生成、Agent 工具调用已实测通过。
- Responses 文本项缺少或返回空的 `annotations` 时补齐空数组，保留已有引用、推理和工具调用。其他响应格式异常仍由 SDK 校验，HTTP 200 校验失败显示明确的兼容性诊断。火山响应结构已通过 SDK 回归测试，未使用真实火山账号验证。
- 「批改管理」与「快速批改」新增「答题卡批量批改」入口。先为已录入试卷标记可复用模板，再批量上传同版式学生答题卡。支持多页 PDF、正反面图片分组、区域预览、跨题和跨学生并发评分；每题使用一次 API 调用，保留计费和结果，重试只处理未完成题目。评分前须在试卷详情准备完整标准答案。
- 图片在模型读图前统一预处理：DocCornerNet 在 320×320 图像上检测角点，再把坐标映射回原图，由 OpenCV 在原始分辨率上矫正透视，并做轻度增强。平整扫描件和不可靠检测保留完整页面。PDF 使用 300 DPI 渲染。模型与许可证随 Worker 打包，无需 PyTorch 或在线下载。
- 网站左下角从 `package.json` 读取版本号，当前为 `v0.1.9`。

## 升级

本版本包含两个数据库迁移：新增答题卡模板、批次、学生结果表，并扩展 credit 流水的任务类型约束。升级时须运行迁移，Web 和 Worker 使用同一版本。发布镜像支持 `linux/amd64`：

```text
ghcr.io/tairuiqu/oh-my-paper:v0.1.9
ghcr.io/tairuiqu/oh-my-paper-worker:v0.1.9
```

发布工作流同时更新这两个镜像的 `latest` 标签。已有自动升级任务会在下一次执行时拉取新镜像；固定版本时在 `.env` 中设置 `APP_VERSION=v0.1.9`。

手动升级时先暂停原有定时升级，在部署目录获取版本并备份：

```bash
cd /opt/oh-my-paper
git fetch origin --tags
git checkout --detach v0.1.9
sudo bash scripts/backup.sh /var/backups/oh-my-paper
sudo install -m 600 .env /var/backups/oh-my-paper/pre-v0.1.9.env
```

保留数据库、存储目录和密钥，设置 `.env` 的 `APP_VERSION=v0.1.9`。当前 shell 若另有 `APP_VERSION`，先执行 `unset APP_VERSION`。然后运行：

```bash
docker compose -f compose.yaml -f compose.release.yaml pull migrate web worker
docker compose -f compose.yaml -f compose.release.yaml stop web worker
docker compose -f compose.yaml -f compose.release.yaml up -d db
docker compose -f compose.yaml -f compose.release.yaml run --rm migrate
docker compose -f compose.yaml -f compose.release.yaml up -d --wait web worker proxy
docker compose -f compose.yaml -f compose.release.yaml ps -a
docker compose -f compose.yaml -f compose.release.yaml logs --tail=100 migrate web worker
```

Docker Worker 已安装 OpenCV，默认使用 `/opt/python-sandbox/bin/python` 和随镜像打包的 ONNX 模型。没有新增必填环境变量。源码部署需要在 Python 环境安装 `tools/python/requirements.txt`，然后构建并重启 Web、Worker；可通过 `DOCUMENT_SCAN_PYTHON` 和 `DOCUMENT_SCAN_MODEL` 指定自定义运行环境。

升级后确认 Web、Worker 为 `healthy`，页面左下角显示 `v0.1.9`，再用一份试卷或照片验证模型调用和扫描。答题卡模式需选用同版式、同页面顺序的模板与学生文件。首次部署参见[通用部署手册](../deployment.zh-CN.md)。

## 验证范围

Lint、类型检查、226 项单元测试、4 项扫描测试、数据库集成测试，以及 Web 和 Worker 生产构建均已通过。样例答题卡经真实 Agent 完成两页共 21 题的区域标记，单题截图评分记录到一次 API 请求。高分辨率测试验证 4800×3200 扫描件保持尺寸，原图透视变换保留单像素细线。
