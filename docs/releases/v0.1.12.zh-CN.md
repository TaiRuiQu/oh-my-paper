# v0.1.12 部署与升级指南

本版本新增侧边栏任务计数动画，并将模型最大输出 tokens 改为 384K（393,216）。

## 功能变化

- 试卷管理、批改管理和快速批改右侧显示当前用户排队或运行中的任务数，每 3 秒刷新。外圈旋转，数字保持静止，任务结束后自动隐藏；支持手机导航抽屉、读屏和系统减少动态效果设置。
- 计数覆盖试卷解析、答案生成与上传解析、整卷批改、答题卡模板和批量评分。同一操作的内部步骤合并计数，快速批改归入自己的导航项。
- 提供商的最大输出 tokens 默认值与允许上限统一为 393,216。迁移将当前功能默认模型使用的提供商更新为该值；新任务使用新配置，已创建任务保留原配置快照。

## 验证

260 项单元测试、类型检查和 Lint 通过。额外数据库验证覆盖用户隔离、已删除任务、超过 50 条历史记录、共享答案去重和答题卡任务；桌面与手机浏览器验证覆盖旋转外圈、静止数字、减少动态效果和任务完成后计数自动消失。模拟 API 请求验证实际发送 393,216 的输出上限。

Web 与 Worker 生产构建均通过。

## 升级

本版本新增 `20261013140000_output_tokens_384k` 数据库迁移，需要在启动新版本前执行迁移。Web 与 Worker 使用同一版本，无新增必填环境变量。镜像支持 `linux/amd64`：

```text
ghcr.io/tairuiqu/oh-my-paper:v0.1.12
ghcr.io/tairuiqu/oh-my-paper-worker:v0.1.12
```

发布同时更新 `latest`。固定版本时将部署 `.env` 的 `APP_VERSION` 设为 `v0.1.12`，在部署目录执行：

```bash
docker compose -f compose.yaml -f compose.release.yaml pull migrate web worker
docker compose -f compose.yaml -f compose.release.yaml stop web worker
docker compose -f compose.yaml -f compose.release.yaml run --rm migrate
docker compose -f compose.yaml -f compose.release.yaml up -d --wait web worker proxy
docker compose -f compose.yaml -f compose.release.yaml ps -a
```

确认 Web、Worker 为 `healthy`，页面显示 `v0.1.12`。其他部署方式参见[通用部署手册](../deployment.zh-CN.md)。
