# v0.1.4 部署与升级指南

本版本将 Word 导出的数学公式从 PNG 图片改为可编辑的 Word 原生 Office Math（OMML）。分式、根号、上下标、求和、积分、极限、向量、矩阵、二项式和分段函数保留数学结构；行内公式与正文同行，独立公式居中。题目配图仍为图片，PDF 继续使用原有 KaTeX 与 Chromium 排版。

Word 导出在 Node.js 中直接生成文档，无需启动 Chromium。新增 `mathml2omml@0.5.0`，运行时代码约 67 KB、无运行时依赖，并复用此前已有的 `xml-js@1.6.11`；具体许可与来源见[第三方依赖说明](../third-party.md)。

## 升级现有部署

发布镜像支持 `linux/amd64`，Docker Compose 需为 v2.24 或更新版本：

```text
ghcr.io/tairuiqu/oh-my-paper:v0.1.4
ghcr.io/tairuiqu/oh-my-paper-worker:v0.1.4
```

如果使用 systemd 定时升级，先暂停 `oh-my-paper-update.timer`；使用 cron 时暂停对应条目。然后在部署目录执行：

```bash
cd /opt/oh-my-paper
git fetch origin --tags
git checkout --detach v0.1.4
sudo bash scripts/backup.sh /var/backups/oh-my-paper
sudo install -m 600 .env /var/backups/oh-my-paper/pre-v0.1.4.env
```

保留原有数据库、`storage/`、`BETTER_AUTH_SECRET` 和 `PROVIDER_KEY_ENCRYPTION_KEY`。在 `.env` 中设置：

```dotenv
APP_VERSION=v0.1.4
```

当前 shell 如果导出了其他 `APP_VERSION`，先执行 `unset APP_VERSION`。按下面顺序拉取、迁移和启动：

```bash
docker compose -f compose.yaml -f compose.release.yaml pull migrate web worker
docker compose -f compose.yaml -f compose.release.yaml stop web worker
docker compose -f compose.yaml -f compose.release.yaml up -d db
docker compose -f compose.yaml -f compose.release.yaml run --rm migrate
docker compose -f compose.yaml -f compose.release.yaml up -d --wait web worker proxy
```

迁移命令成功后才启动应用。从 v0.1.3 升级没有新增数据库迁移或必填环境变量；从 v0.1.2 或更早版本升级仍需应用 v0.1.3 的软删除及版本字段迁移，以上命令会自动补齐。Web 和 Worker 保持同一版本。

## 验收

```bash
docker compose -f compose.yaml -f compose.release.yaml ps -a
docker compose -f compose.yaml -f compose.release.yaml logs --tail=100 migrate web worker
docker compose -f compose.yaml -f compose.release.yaml exec -T web node -e \
  'fetch("http://localhost:3000/api/health").then(async r=>{console.log(await r.text());process.exit(r.ok?0:1)}).catch(()=>process.exit(1))'
```

Web / Worker 应为 `healthy`，健康接口返回 `{"status":"ok","database":"ready"}`。选择含分式、根号或矩阵的试卷导出 Word，在 Word 中点击公式，应能直接编辑分子、分母、上下标等结构，且公式没有图片选框。检查原有题号、正文、表格和配图，以及 PDF 的横向四栏样式。

已有 `.docx` 不会自动转换，需要从试卷详情重新导出。公式输入继续使用原来的 LaTeX 语法；遇到语法错误或不支持的数学结构，导出会提示对应公式并要求修正，避免静默丢失内容。

## 首次部署、源码构建与回滚

- 首次部署和 ARM 源码构建沿用 [v0.1.3 部署指南](v0.1.3.zh-CN.md)，将 tag 和 `APP_VERSION` 替换为 `v0.1.4`。镜像已包含依赖，无需在宿主机安装数学转换工具。PDF 仍需浏览器，镜像内已提供。
- 从 v0.1.3 升级后需要回滚时，将 `APP_VERSION` 改回 `v0.1.3`，拉取镜像，停止 Web / Worker，再运行 `docker compose -f compose.yaml -f compose.release.yaml up -d --no-deps --wait web worker`。数据库无需降级，Word 导出恢复为图片公式。
- 验收后可恢复原来启用的定时器或 cron。固定 `APP_VERSION=v0.1.4` 时只跟踪本版本；删除这一行后才跟随后续发布的 `latest`。
