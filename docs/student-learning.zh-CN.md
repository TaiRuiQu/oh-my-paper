# 学生错题、班级与练习

使用流程：上传完整作答卷或选择题套上传作答 → 标准答案准备完成后批改 → 核对分数 → 错题本 → 原题重练或相似题练习。完整解析逻辑见 [试卷与批改流程](paper-workflow.zh-CN.md)。

## 试卷与班级

试卷板块 `/dashboard` 上传并保存电子题套，可选择是否生成标准答案。题套详情可以对照原图修正题干、分值与答案，保存生成新版本。未生成的答案须先补充或生成才能批改。HTML 下载包含公式和可用的干净配图，可在浏览器中打印或另存为 PDF；另有 Markdown/JSON 下载。

批改板块 `/grading` 支持直接上传有题干的完整作答卷，现场建立题套并准备答案；也可选择已保存题套，上传已作答试卷或答题卡。只有答案、没有题干的答题卡需要题套。标准答案优先整理原件参考答案，也可以由教师填写或从已识别的参考答案文件导入，按明确题号与板块匹配。

教师在班级管理创建班级和学生，学号在班级内唯一，姓名可以相同；可选关联已注册学生邮箱。创建批次时选择标准答案可用的题套，固定当时的题套版本。逐位添加学生的多页文件，再提交待批改列表；每位学生独立解析作答，复用同一版本的题目与标准答案。失败项保留供重试，后续编辑题套不改变已有批次。

绑定学生可查看自己的学习记录，其他学生无权访问，学生不能修改教师分数。

## 错题与练习

错题本使用当前试卷版本的最新完成报告。错答、部分得分、空答分别展示；识别失败和待核对题目不计为知识错误。人工调分按有效分数重新派生错题，改为满分后移出错题本。同一试卷版本和题目重复批改不会重复计数；不同来源且没有明确题套关联的题目不自动合并。

原题练习在准备阶段独立求解并核对练习参考答案，提交后使用固定答案评分。作答前页面和 API 隐藏答案、评分规则与历史反馈。每次尝试独立保存，连续两次原题答对标为已巩固，后续答错会撤销；相似题答对不自动标记原题已掌握。

相似题每次生成三道文字题，通过独立请求检查条件、答案、评分规则和重复内容后才展示。失败或核对未通过时整组不发布，当前不生成几何图片。该模型核对过程尚未经过正式教学准确率评测。

在线练习支持文本提交，页面也保留手写作答上传入口。该入口目前调用普通试卷解析，尚未按练习题套接入独立作答提取，识别作答可能为空；用户需要核对并填写后再提交。批改板块的作答上传使用完整作答文档管线。

“整理知识点”使用现有合法分类，知识点汇总按待巩固题数排序。当前是初中数学优先的通用学科分类，没有正式出版社或教材版本的知识点树。巩固指标只用于安排复习，不能代表整个知识点的掌握程度。

## 运行与回归

`pnpm run dev` 默认同时启动 Web 和 Worker。只开页面用 `dev:web`，另开终端运行 `dev:worker`。Worker 离线时新任务返回 `503`，已有队列任务保留。

`pnpm run test:learning-web` 使用临时测试数据验证账号关联、越权、练习答案保密、合法分类和人工调分后的错题同步；它不验证手写入口或相似题的真实模型准确率。题套、答题卡、完整作答与证据接口使用 `pnpm run test:exam-web` 回归，详见 [集成验证](ai-web-validation.md)。
