# 学生错题与练习

使用流程：上传已作答试卷 → 自动识别与批改 → 核对分数 → 错题本 → 原题重练或相似题练习。

首页默认快速批改；空白试卷或参考答案文件选择“整理空白试卷”。识别结果可对照原图修正题干和分值，修正保存为新的试卷版本，旧批改保留原始证据。下载试卷得到包含公式和清晰配图的独立 HTML 文件，可以用浏览器打开、打印或另存为 PDF；更多下载保留原有 Markdown/JSON。

批改设置可导入另一个已识别文件中的参考答案与评分标准，只匹配明确题号/章节，不把学生作答当作参考答案。无法对应的题目保留原设置。没有提供参考答案时仍独立求解、复核，建议分数经人工核对后计入总分。

错题本只采用当前试卷版本的最新完成报告。错答、部分得分、空答分别展示；识别失败和待核对不计为知识错误。人工调分按有效分数重新派生错题，即使模型旧判定仍为错误，改为满分后也会移出错题本。相同试卷、版本、题目不会因重复批改重复计数。不同来源且没有明确模板关联的题目不自动合并。

原题练习开始前，页面和 API 不提供答案、评分规则或原始批改反馈。提交后使用固定参考答案和现有评分服务批改。练习尝试独立保存；连续两次原题练习答对标为已巩固，之后答错会撤销。相似题正确不自动标记原题已掌握。该指标仅用于安排复习，不能代表对整个知识点的掌握程度。

相似题每次生成三道文字题，独立请求检查条件、答案、评分规则和重复内容后才展示。生成失败或核对未通过时整组不发布；作答继续复用评分服务。当前新题暂不生成几何图片。模型独立核对并不能替代教学准确率评测。

“整理知识点”可选择合法分类；知识点汇总按待巩固题数排序。当前分类是初中数学优先的通用学科分类，**没有冒充某一出版社或教材版本的正式知识点树**。接入正式教材需要指定版本并提供授权数据。错题记录和练习状态保存在 PostgreSQL，刷新或离开页面不丢失。试卷重新识别后，快速批改按新的来源版本生成独立报告；旧报告仍保留原来的输入。

教师在“班级”创建班级、学生和批次。学号在班级内唯一，姓名可以相同。可选关联已注册学生邮箱。逐位选择学生和文件，加入待批改列表，再一次提交全部作答；多张照片组成同一位学生的一份提交。任务独立执行，提交失败项保留供重试。批次展示每位学生的进度、已计分和待核对数；绑定学生可在自己的错题本复习，其他学生无权访问。学生不能修改教师分数。

当前批次针对各自带题目的完整作答，逐份独立识别和求解；尚未实现答题卡模板匹配及跨学生复用答案版本。在线练习支持文本作答，也可展开“上传手写作答”，上传 PDF 或照片，识别完成后填入并核对作答，再提交评分。无法辨认或无法对应的作答由用户补充，不从参考答案猜测。

## 启动与回归

`pnpm run dev` 默认同时启动 Web 和 Worker。只启动页面时使用 `pnpm run dev:web`，另开进程运行 `pnpm run dev:worker`。Worker 每十秒写入数据库心跳；超过 45 秒未收到心跳时，新任务返回可理解的 503 提示，避免没有消费者仍不断接受任务。已经入队的任务保留，Worker 恢复后继续。识别有 30 分钟总时限，批改有两小时总时限，模型调用仍有独立超时。任务可取消，产物写入用 jobId/attempt/status 防止旧任务覆盖重试。

运行 `pnpm test`、`pnpm run test:queue`、`pnpm run test:exam-web`、`pnpm run test:learning-web`。后两项要求 Web/Worker 已启动。识别集成测试先上传损坏 PDF，再上传正常文件，验证消费者继续工作；学习集成测试验证学生绑定、越权、答案隐藏、合法分类及调分后错题同步。
