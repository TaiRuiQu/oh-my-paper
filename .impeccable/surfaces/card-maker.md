# 答题卡制作工作台

Mode: Operate。教师从考试试卷制作、检查并保存可打印和扫描的答题卡。

## Direction contract

THESIS: 延续智学网参考图中教师熟悉的纸面制作习惯，用灰色画布、白纸和右侧配置区降低迁移成本。

OWN-WORLD: 应用沿用 Geist 与 Noto Sans SC，自托管中文字体、可见焦点和真实印刷几何。主要操作为青绿（#08745f），画布为灰色（#dce1df），右栏分组条为浅灰（#eff2f0）；按钮、字段和普通容器使用紧凑 3px 圆角。

STORY: 选择试卷或从空白卡开始 → 设置纸张和栏数 → 添加、选择及调整题区 → 预览 → 保存 → 下载正式卡或用于考试。题目增删、重排在保存时原子生成试卷修订版与关联答题卡，历史考试保留原关联；只修改试卷文字时保留题目 ID。

FIRST VIEWPORT: 桌面 190px 主导航与 54px 账户栏之后，以灰色卡面画布和 300px 白色制作区并排。制作区包含卡面设置、题型添加、题目列表和选中对象属性；浅灰条分隔信息。画布与配置内容独立滚动，底部两列动作持续可见：保存、预览、下载、锁定、复制为新卡、用于考试。

FORM: 独立页面中的真实卡面编辑器。纸张按 A4 纵向、A3 横向保持比例，支持适应宽度、10%–300% 缩放和恢复 100%、选中、拖动、方向键移动、缩放和精确坐标；配置使用紧凑表单、分段选择、栏数图示和具名开关。卡面为黑白印刷内容，青绿仅用于应用工具与选中反馈，不进入正式印刷正文。

FINISH: 使用保存后的持久化版式打印和扫描；正式 SVG 下载前必须保存。锁定状态随版式保存；已用于扫描的卡修改后保存为新版。桌面验证纸面／面板独立滚动，手机验证固定动作区与安全区留白，键盘验证选择、移动、缩放和可见焦点。截图仅作为视觉记录，不替代交互或实物扫描验收。

## Capabilities and boundaries

- 学科预设覆盖语数英、物化生、政史地；支持多页、A4／A3、分栏、题区和文本标注。
- 客观题保留填涂几何，主观题支持横线与作文格；四角定位点与页面识别码维持扫描所需结构。
- 考号支持六位数字填涂或粘贴条形码，按班级生成独立 A4 条码标签纸，每人份数可选。填写格连续相接；注意事项参照 examples 样张完整呈现。页面识别码位于左上定位点右侧，用于核对模板与页码。
- 新增题目保存到试卷修订版后，教师在对应试卷完善题干、答案和评分标准。
- 作业使用含作答空间的练习册；独立答题卡服务考试。

## Responsive behavior

1100px 及以下主导航收至 168px；1000px 及以下制作区为 280px。760px 及以下导航转为 Sheet，制作区堆叠在卡面后；卡面独立局部滚动、支持全尺寸查看，底部六项动作固定为两列。编辑页保留底部空间，避免配置内容被动作区遮挡；预览 Sheet 位于动作区上方。
