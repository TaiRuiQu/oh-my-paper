# 试卷识别工作台

## Mode
Operate

## Confirmed direction
用户确认沿用现有简洁中文界面，以“上传试卷 → 查看进度 → 核对结果/下载”为主流程。保留现有浅色纸面、深绿色操作色、中文无衬线字和 8–12px 圆角控件。此任务为现有界面的功能扩展。

## First viewport
工作台立即提供文件选择入口和单一的“开始识别”主操作。提供清晰文件/页面限制与未配置模型时的解决路径，随后显示最近试卷与真实后台状态。

## Interaction
多图可上下移动以确认页面顺序。处理完成后按页并排查看原图和结构化题目，作答/批注独立切换。管理员保存多个提供商、切换模型和提示词并测试连接。桌面双列在手机上顺序堆叠。

## Quality bar
无需理解 API 即可上传和查看试卷；设置字段有标签与可恢复错误；无密钥回显；响应式无横向溢出；全部原图和下载资源检查归属；待核对内容有明确提示。不得将模型核对等同于识别准确率证明。
