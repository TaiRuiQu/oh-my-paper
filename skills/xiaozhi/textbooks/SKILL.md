# 教材与单元知识点

用于题目归类、单元组题、学习范围判断和推题。默认目标为统编／人教系列，普通六三学制小学、初中及高中；五四学制、英语分支、数学 A/B 版、音乐记谱版本须单独匹配。

## 按需读取

使用 `read_skill_resource`，技能 ID 为 `textbooks`：

1. 读取 [references/catalog.json](references/catalog.json)，根据学段和学科找到 `subject_catalogs[].catalog`，再读该学科索引。
2. 索引每册给出 `id`、`version`、`revision_label`、`grade`、`volume` 和 `resource`。确定目标后只读该册所在资源，按 `id` 选中 `books` 条目。
3. 读取 [references/teaching-guidance.md](references/teaching-guidance.md)，把单元概念转成可用于题目归类、难度判断和补弱的维度。来源或版本存在疑义时读 [references/sources-and-coverage.md](references/sources-and-coverage.md)。

现有 500 册官方同步教学树：普通小学 199、初中 136、高中 98 册，五四学制另有 67 册。新旧教材、分支版本分别计册，不能把它们当作 500 种现行教材，也不能宣称完整覆盖全国版本。全部目录均有真实层级和来源；逐册纸质教材版次、ISBN 与版权页尚未核实。出版社书目附录另列 303 册，仅有书目核验，不计入单元覆盖。

## 先匹配实际教材

先从用户已有信息或试卷封面确认学段、学制、学科、年级、上下册/必修模块、版本分支、修订批次和教学进度。信息不足时可先列对应候选，关键版本不清时请求封面、版权页或目录。不能默认同年级所有人教教材目录相同。

`新教材`、`旧教材`是平台原始标签；它们不能证明具体首版年份。义务教育 2022 年课标、2024 年起修订教材及分年级换用可能并存；高中 2019 年起新教材与后续修订也不能按“高中”标签直接判定。先比对实际单元名称和课题顺序，再采用该树。

## 读取结构与诚实使用

- `units[].title`、`children`保留官方同步教学树的层级，可能含复习、实验、附录、活动，不保证与某个印次出版目录逐字一致。不得把课时节点强行升格为教材单元。
- `units[].topics`是根据该节点和下级标题编写的概念范围，`topics_kind=editorial_from_official_headings`。它们是知识点整理入口，不是官方课标原文，也不表示已经穷尽定义、公式、词汇、语法或考点。
- 结合题目实际解法细化概念、方法、实验/材料能力和先修依赖；保留官方单元名，编辑归纳单独标注。没有证据时用“候选关联”，不要伪造教材页码或全国统一考纲。
- 整理/推题结果至少说明匹配的版本与册次、实际单元、知识点、适合的学习阶段和理由；多单元题可多标签。以用户指定范围、实际教学进度和学生错因决定练习，不以教材所在年级直接推断学生已掌握。

## 缺失或不一致

先检查 `catalog.json` 的 `unverified` 与该学科是否有对应版本。找不到的册次、版权年或目录必须明确“当前资源未核实/未收录”，不能用泛化主题或旧版目录补成事实。

当前小纸是否有公网检索能力以实际工具列表为准；不要假定能联网。无公网工具时提供 [国家平台](https://basic.smartedu.cn/tchMaterial) 或 [人教电子教材](https://jc.pep.com.cn/) 链接，请用户核对或提供目录文字/图片；有 `view_image` 可读目录图片，有可用的 `sandbox` 时可读取用户原始附件中的目录与版权页（按其工具说明，网络能力单独确认）。能查官方来源时核对目标版本后再使用。用户提供的目录可用于当前任务，标明“用户提供，未与出版社交叉核实”，不要声称永久写入此内置 Skill。
