# 从教材单元到题目知识点与推荐

以下为编辑归纳的教学使用建议，不是官方课程标准逐条转录。先取对应版本的真实单元和下级课题，再用本表决定需要分析哪些能力；不能拿这张通用表替代目录。

| 学科                   | 单元知识点如何细化                                                                                         | 整理与推题时观察的能力和边界                                                                                      |
| ---------------------- | ---------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 语文                   | 从课文、阅读任务、习作、口语交际、语文园地提炼字词、文体、表达方法、阅读策略和写作任务；主题与语文能力分开 | 字词基础→信息提取→结构与表达分析→迁移表达；文言实虚词、句式与鉴赏据实际篇目；整本书阅读不能只用节选替代           |
| 数学                   | 从章/节概念提炼定义条件、性质、公式、运算与解题方法；注明题目用到哪些前置概念                              | 运算准确性、表征转换、推理证明、建模；同一单元可有不同难度，不能靠大数/长题面提升难度；新内容不混入未教的技巧     |
| 英语（含各起点与分支） | 从单元主题及真实下级语言活动分析词汇、语音、交际意图、阅读/写作任务；语法必须有题目/正文证据               | 听说读写、信息定位、语篇理解、得体表达；Unit 主题不等于该单元语法表；PEP、精通、一年级起点与初中不同主编分别匹配  |
| 物理                   | 从节标题与题目推导概念、量与单位、适用条件、模型、规律、实验变量和图像                                     | 概念辨析→模型识别→规律应用→实验设计/证据解释；力学/电学先修来自真实教学进度；理想模型条件与生活近似分开           |

| 体育与健康             | 从单元技能、规则、健康行为和运动文化提炼动作要领、活动策略、自我管理                                       | 规则理解、动作观察与实践表现；纸笔题不能替代运动技能评价；推题需考虑实际训练条件和个体情况                        |
| 信息技术               | 从项目提炼数据表示、算法、编程、系统/网络、数据管理、人工智能与安全伦理                                    | 任务分解、模型/算法选择、调试、数据解释；软件操作版本不同要辨明；只有信息技术高中目录时不冒充义务教育信息科技教材 |

| 艺术／影视／戏剧／舞蹈 | 从项目/作品提炼媒介语言、结构、表演表达、创作流程和文化语境                                                | 欣赏、比较、策划、合作、呈现；不同艺术课程可交叉但保留各自教材模块，不能用音乐或美术单元代填                      |

## 标签与先修依赖

为每道题形成可解释的记录：`学段/学制/学科/版本/修订标签/册次/官方单元路径/概念/方法或能力/学习阶段/证据`。以官方章节路径定位教学范围，以题目实际解法确认概念和方法；一个题目可跨多个单元。

课前诊断先检查直接前置，例如目标是“一元二次方程”时先看方程意义、整式运算与因式分解是否已经学过并掌握。前置关系是结合真实目录和解法提出的教学推断，不是目录中明示的先修链。

推荐练习先用已学范围和核心错因筛题，再选择基础巩固、易混辨析、同概念变式、跨情境迁移。难度用概念个数、推理步数、表征转换、情境陌生度、实验/材料处理要求解释。无学生作答证据时说“建议诊断”，不声称已经发现薄弱点；没有实际题库结果时不得伪造题目 ID、来源或可用题数。

## 结果样式

“教材匹配：人教 A 版，必修第一册，实际版权年待用户确认；单元：第一章 集合与常用逻辑用语；知识点：集合关系与运算（根据实际节标题和题目归纳）；错因证据：把元素属于集合与集合包含关系混用；推荐：先做符号辨析，再做集合关系变式；范围：只用当前已教内容。”

此例仅展示说明方式。使用时必须重新从目标册的真实资源和实际作答取证，不能把示例当作学生事实。
